# Inventory-Tracker-App
CS-360 Inventory App
App Overview
My app helps users manage inventory by allowing them to log in, add items, update quantities, and remove items. 
UI Design
The app includes login, inventory, add item, and SMS settings screens. I kept the design simple and easy to navigate.
Development
I developed the app one feature at a time, which helped me organize my code and solve problems.
Testing
I checked the app's screens and features for errors. Testing helped me identify problems and improve functionality.
Challenges
One challenge was connecting the screens and features. I worked through issues step by step to improve the app.
Skills Demonstrated
I am most proud of the inventory screen because it makes viewing and managing items simple and organized.
